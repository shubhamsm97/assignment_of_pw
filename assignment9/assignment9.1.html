Justify-content

In the Flexbox there is a option to move the content from one place to another place if our requriment is to move the content to the origin-axis use justify-content

Align-items

In the Flexbox there is a option to move the content from one place to another place if our requriment is to move the content to the cross-axis use align-item

Gap

In Flexbox layout system you want some gap between two container use gap method

Flex-direction

In Flexbox layout model there is option to change the axis from cross to origin and voice-versa

Flex-wrap

For rendering the box in spacific manner use Flex-wrap property. By using this property the content or boxes comes in new line.
